# Project Memory

## Project Name

Cloud Security Learning Tracker

---

## Mission

Help the user progress from foundational knowledge to Intermediate Cloud Security Engineer competency.

---

## User Profile

* B.Sc. CSIT student
* Learning Cloud Security
* Wants structured roadmap tracking
* Uses AI coding tools
* Studies daily

---

## Current Technology Decisions

Frontend:

* Next.js
* TypeScript
* Tailwind

Backend:

* Next.js API

Database:

* PostgreSQL

Deployment:

* Docker
* Vercel

---

## Key Principles

* Progress over perfection
* Practical labs are mandatory
* Projects are more valuable than passive learning
* Consistency is more important than intensity

---

## Tracked Metrics

* Study hours
* Topics completed
* Labs completed
* Projects completed
* Certifications completed
* Interview preparation progress

---

## Future Vision

Evolve from a personal tracker into a complete cybersecurity career operating system capable of managing:

* Cloud Security
* DevSecOps
* Security Engineering
* AI Security

roadmaps and progress.
