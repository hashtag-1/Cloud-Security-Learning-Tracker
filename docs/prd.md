# Cloud Security Learning Tracker - Product Requirements Document

## Overview

A personal web application designed to track progress toward becoming an Intermediate Cloud Security Engineer.

The application will help the user:

* Track learning progress
* Manage roadmap phases
* Record completed topics
* Track practical labs
* Track projects
* Maintain study streaks
* Store notes and resources
* Visualize overall progress

---

# Problem Statement

Learning Cloud Security involves hundreds of topics, labs, projects, and certifications.

Traditional note-taking systems do not provide:

* Structured roadmap tracking
* Practical lab tracking
* Project tracking
* Skill progression visualization

The application solves this problem.

---

# Goals

## Primary Goals

* Track roadmap progress
* Track daily study sessions
* Track lab completion
* Track project completion
* Measure progress toward intermediate-level competency

## Secondary Goals

* Generate study analytics
* Track certifications
* Track interview preparation
* Build personal knowledge base

# User

Single User (Owner)

No multi-user support in v1.

---

# Core Features

## Dashboard

Displays:

* Current phase
* Current streak
* Total study hours
* Topics completed
* Labs completed
* Projects completed

---

## Roadmap Tracker

Tracks:

* Phase
* Topic
* Microtopic

Statuses:

* Not Started
* In Progress
* Completed
* Needs Revision

---

## Study Session Tracker

Record:

* Date
* Duration
* Topics studied
* Notes

---

## Lab Tracker

Store:

* Lab name
* Category
* Difficulty
* Completion status
* Lessons learned

---

## Project Tracker

Store:

* Project name
* Description
* Technologies used
* Status
* GitHub link

---

## Knowledge Base

Store:

* Notes
* Commands
* Cheat sheets
* Security concepts

---

## Analytics

Show:

* Progress by phase
* Hours studied
* Completion rate
* Weekly trend

---
