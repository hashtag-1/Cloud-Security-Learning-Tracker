# Project Rules

## General Rules

* Simplicity over complexity
* Mobile-first design
* Clean architecture
* Type-safe code

---

# Development Rules

* TypeScript only
* No any types
* Reusable components
* Feature-based folder structure

---

# UI Rules

* Consistent spacing
* Accessible components
* Responsive design

---

# Data Rules

* No duplicate data
* Validation required
* Use UUIDs

---

# Security Rules

* Input validation
* Parameterized queries
* Authentication required
* Authorization checks

---

# AI Coding Rules

When generating code:

* Generate complete files
* Explain assumptions
* Avoid placeholder implementations
* Follow existing project structure
* Prefer maintainable code over clever code

---

# Documentation Rules

Every feature must include:

* Purpose
* Data flow
* Dependencies
* Acceptance criteria
